# Entrega-Final-Ecosistema-de-Automatizaci-n-IA-Aut-nomo-para-Negocios
El proyecto final integra todo el stack del curso en un ecosistema de automatización funcionando en vivo que resuelva un proceso de negocio de extremo a extremo (ej. gestión de leads, atención al cliente con memoria, generación de propuestas o pipeline de contenido).
